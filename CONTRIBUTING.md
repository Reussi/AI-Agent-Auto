# Mitmachen / Contributing

Danke für dein Interesse an IA Agent Auto! / Thanks for your interest!

## Fehler melden und Ideen vorschlagen
Bitte ein **Issue** anlegen und beschreiben: Handy-Modell, Android-Version, Android-Auto-Version,
was du gemacht hast und was passiert ist. Screenshots helfen.

## Code beitragen (Pull Requests)
1. Repository forken und einen eigenen Branch anlegen.
2. Änderung klein und verständlich halten, `./gradlew assembleDebug lintDebug` muss fehlerfrei laufen.
3. Pull Request mit kurzer Beschreibung öffnen.

**Wichtig:** Mit dem Einreichen eines Beitrags räumst du dem Rechteinhaber die in Abschnitt 4 der
[LICENSE](LICENSE) beschriebenen Nutzungsrechte ein (auch für die kommerzielle Version im Play Store).

## Niemals einchecken
- API-Schlüssel (`sk-ant-…`), Home-Assistant-Token, Passwörter
- Signaturschlüssel (`*.jks`, `*.keystore`) und `keystore.properties`
- `local.properties`
